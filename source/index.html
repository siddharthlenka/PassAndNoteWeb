Three platforms. One connected project.

Choose a repository to read the implementation, setup instructions, and platform limitations.

iOS

PassNoteVault

The mobile vault for passwords and secure notes, built with Swift and SwiftUI. GRDB and SQLCipher manage encrypted local storage; CryptoKit, Keychain, and device biometrics support vault protection.

View iOS source ↗

ANDROID

PassAndNoteAndroid

The Android vault built with Kotlin and Jetpack Compose. SQLCipher, Android Keystore, and strong biometric unlock support the local vault and encrypted backup workflow.

View Android source ↗

WEB

PassAndNoteWeb

This product website and its read-only recovery viewer, built with HTML, CSS, JavaScript, and Web Crypto. Compatible backup files are decrypted locally in the browser tab.

WHAT TO EXPLORE

Follow the data from vault to backup.

The mobile apps keep the primary vault on your device. Manual encrypted exports provide a separate recovery path.

  • Vault-key generation, password derivation, and key storage
  • SQLCipher database access and record handling
  • Encrypted .pnvault, .pnpass, and .pnnote exports
  • Browser-side backup validation and decryption

Source availability and security

Public code helps people inspect design decisions and report problems. It does not establish that the app has passed an independent security audit, and it does not verify the contents of published app binaries.

The repositories are public for inspection with all rights reserved. Review each repository’s licence notice and third-party dependency terms before reusing code.

Found a potential vulnerability? Report it privately to support@passandnote.com. Do not include real passwords, vault files, or private notes.
