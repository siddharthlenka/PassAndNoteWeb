FROM MOBILE TO WEB

How to get the encrypted file

The mobile app remains the primary place to create, edit, and organize your vault. The website is only a read-only recovery viewer.

01

Unlock the mobile app

Open Pass & Note on your phone and unlock the vault with your Master Password or enabled quick-unlock method.

02

Choose what to export

From Vault, choose Export Vault for a complete .pnvault. In Passwords or Notes, use Export for a section package.

03

Confirm the Master Password

The app verifies the Master Password and uses it to protect the new encrypted export file.

04

Save the file somewhere safe

Save it using your phone's file picker. Move it to the computer only when recovery access is needed.

05

Open it on this website

Choose the encrypted file above and enter the same Master Password that was active when the export was created.

06

Close the viewer when finished

Use Close File to clear readable values immediately. The viewer also locks in the background and expires after two minutes of inactivity by default.

READ-ONLY BY DESIGN

What the recovery viewer does—and does not do

What it does

  • Decrypts compatible files locally in memory
  • Displays passwords and notes as read-only values
  • Allows reveal and copy for password recovery
  • Locks whenever the page goes into the background
  • Clears the file after two minutes of inactivity by default
  • Allows a temporary extension to five or ten minutes

What it never does

  • Creates or stores a browser vault
  • Adds, edits, or deletes records
  • Creates downloadable encrypted or readable exports
  • Saves the Master Password
  • Intentionally uploads vault contents to a server
!
The Master Password cannot be recovered.

An encrypted backup can only be opened with the password used when it was created. Changing your current mobile password does not change passwords protecting older export files.

ABOUT PASS & NOTE WEB

A recovery bridge, not a second vault.

Pass & Note Recovery Viewer exists for situations where a user cannot access their mobile device but still has an encrypted backup and its Master Password.

Mobile remains the authoritative vault experience. This website deliberately provides no editing, encryption, or permanent storage functionality.

Privacy and hosting information

Vault processing is local. Like every hosted website, the web host may receive ordinary connection information when serving files, such as IP address, time, and browser type. That is separate from the encrypted backup contents.

Security limitations

No website can protect against a compromised device, malicious browser extension, clipboard monitoring, screenshot, or someone using the computer while values are visible.
